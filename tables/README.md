# 五张在线表模板

这些 CSV 仅作**字段示例**，不是 `index.html` 的数据库，也不会因放入仓库就自动与网页双向同步。请让 WorkBuddy 在自己的资料库创建表格，并按实际字段调整页面读写映射。

| 表 | 存什么 | 关键关联 |
|---|---|---|
| `ideas_topics.csv` | 灵感、正式选题、状态与一句话大纲 | `id` |
| `radar.csv` | 对标内容、平台、钩子和可借鉴点 | `id`；转选题时生成新的 `ideas_topics.id` |
| `assets.csv` | 开头、标题、结构、结尾等脚本资产 | `id` |
| `schedule.csv` | 待办、发布排期、打卡记录 | `topic_id` 关联选题 |
| `metrics.csv` | 已发内容的数据与复盘笔记 | `topic_id` 关联选题 |

所有表都包含稳定 ID 和更新时间。不要以标题作为唯一键。以下数字和内容均为虚构示例，方便验证读写，不代表真实账号表现。
