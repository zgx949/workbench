# 把提示词改成自己的工作台

这份提示词的顺序是：**先给参考 → 指定数据存储 → 描述日常动作 → 写验收标准**。生成页面时，最容易漏掉的是后两项。

1. **先改人群与平台。**把“泛自媒体博主”缩成你自己真正的使用场景，如小红书图文、抖音口播或公众号。删掉不会用的字段和板块。
2. **保留主循环。**从“今天记录一个灵感”开始，检查它能否变成选题、进入排期、发完录数据，最后在复盘中被找到。
3. **保留数据源约束。**在线版以资料库表格为正式数据源。若想做纯离线工具，则改成 `localStorage` 并删除在线同步承诺。
4. **用动作验收。**不要只说“支持同步”，要指定“页面新增 → 表格出现；表格修改 → 页面回显”。
5. **最后再定视觉。**可换成别的配色，但不应先花大量指令写装饰，导致核心数据流被挤掉。

本仓库的 `index.html` 适合直接体验交互和离线使用；[prompt.md](../prompt.md) 用于生成自己的在线版。它们对应两种存储方式。
