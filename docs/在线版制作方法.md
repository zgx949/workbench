# 在线版制作方法与验收

## 1. 准备

准备一个 WorkBuddy 账号和自己的资料库空间。打开 [完整提示词](../prompt.md)，改掉赛道与平台占位内容。参考页面是[公开工作台](https://workbuddy.link/p/VEmid0pCbQMW6V1GnGNAdm)。不要把公开示例页当成自己的可编辑页面。

## 2. 生成

把参考链接与提示词一起发给 WorkBuddy。能用「一键做同款」时先走该入口；否则让它按提示词创建 HTML 页面和五张表。检查资料库中确实出现五张表，并查看字段是否能承载所有可编辑模块，特别是灵感、爆款雷达、待办与复盘。

建议先用虚构数据验证，确认功能后再导入个人内容。页面上的“云端同步”字样不是验收证据。

## 3. 两个方向都测

| 操作 | 应看到的结果 |
|---|---|
| 在自己的可编辑页面新增一条选题 | `ideas_topics` 表中出现同 ID 记录，标题和大纲一致 |
| 在在线表格修改这条选题标题 | 刷新页面后显示新标题，原记录没有被复制成第二条 |
| 在页面编辑、改期和删除 | 对应表记录正确更新；其他表的关联 ID 没有错位 |
| 换一个有权限的设备重新打开 | 读到相同记录；不会被旧 `localStorage` 覆盖 |
| 断网再联网 | 页面明确显示未同步状态；没有静默覆盖在线记录 |

如果任何一步失败，先让 WorkBuddy 修读写映射，再发布。五张表只是一种组织方式，关键是所有可编辑数据都有明确归属和稳定 ID。

## 4. 发布

WorkBuddy 官方文档说明，「发布为网站」生成的是供访问的只读链接；邀请协作是参与编辑的入口。录教程时，双向同步应在自己的资料库编辑页拍摄。发布前检查页面及其引用表格是否含个人、客户或账号敏感内容。

## 5. 常见误区

- **只有漂亮页面，没有在线表格**：它是静态页或本地版，不能叫在线工作台。
- **页面新增能写表，表格改动不回显**：只实现了单向写入。
- **按标题匹配记录**：重名或改标题后容易错位；使用稳定 ID。
- **本地缓存覆盖云端**：打开页面时应先确定在线表格与缓存的优先级及冲突处理。
- **示例数值当真**：所有样例都要标注为虚构，复盘结论只根据自己的数据生成。
